The approach

Start with what is going wrong

A lot of fabrication work begins with an imperfect situation: something does not fit, something failed, the original plan changed, or an inspector needs a condition corrected before the project can move forward.

That is not a nuisance. That is often the actual job. Stanrod is there to help find the next workable step.
