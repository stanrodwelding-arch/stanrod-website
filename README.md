# Stanrod Website

Custom static website for Stanrod Welding & Plasma LLC.

## Cloudflare deployment
- Build command: leave blank
- Deploy command: `npx wrangler deploy`
- Static assets directory is configured in `wrangler.jsonc` as `./public`
